# BJFU-Beijing-Surface-Water-Resistome

Nitrate-associated microbial hosts structure resistomes across a megacity's surface waters
(Nature Water submission).

## Reproducibility note

- All statistical analyses and individual figure panels are generated by the scripts in this
  repository from the published SI workbook `data/Supplementary_Tables.xlsx` (16 tables) and
  other in-repository inputs.
- Final multi-panel figures (Fig. 1-6, Extended Data Figs. 1-10) were assembled manually in a
  vector graphics editor.
- Scripts are organized by the paper's narrative flow (Fig 1 -> 6, then ED Figs); each script
  generates one analysis or one figure panel.

## Data

The input file is `Supplementary_Tables.xlsx` (16 tables), published as Supplementary
Information alongside the article. It is not copied into or committed to this repository.
Download it and place it at exactly `data/Supplementary_Tables.xlsx` before running scripts.

Additional in-repository data files (derived from the analysis pipeline and shipped
with the code): `05_nitrogen_metabolic_potential/05a_bubble_data.xlsx` (MAG-level
nitrogen-gene counts for Fig 5a; MAG-level ARG carriage is provided by Supplementary Table 11),
`05d_network_edge.csv` and `05d_network_data.xlsx`
(Fig 5d network edges and co-host MAG data).

## Notes on figures without code

The following figures were produced without custom analysis code and are not
reproduced by scripts in this repository:

- **Fig 1a** (sampling map): drawn in ArcGIS; bubble size = total ARG abundance
  per site (sum over ARG subtypes in SI Table 4, averaged across replicate samples).
- **Fig 3a** (MAG reconstruction workflow): schematic diagram.
- **Fig 3b** (MAG phylogeny): visualized in iTOL from the RAxML tree
  (`03_genome_resolved_hosts/03b_mag_phylogeny.tre`);
  no plotting code.
- **Fig 3c** (ARG-host network): visualized in Cytoscape from
  `03_genome_resolved_hosts/03c_arg_host_network_data.xlsx` (kingdom x phylum x ARG hits);
  no plotting code.
- **ED Fig 5** (host-ARG network): visualized in Cytoscape from
  `07_ed_figures/07e_edfig5_data.xlsx` (ARG subtype x genus x value);
  no plotting code.
- **Fig 5b** (nitrogen pathway comparison): hand-drawn schematic; underlying
  data are in SI Table 15.
- **Fig 5d** (ARG-NCG-host network): visualized in Cytoscape from the edge
  list `05d_network_edge.csv` and co-host MAG data `05d_network_data.xlsx`;
  session file `05d_arg_ncg_network.cys` included; no plotting code. The
  18 host nodes are ARG-host SGBs (SI Table 15 ARG_host = Yes) carrying NCGs.

## Data inputs and reproducibility

Run analysis scripts from repository root unless a script states otherwise. Input data files
that are user-downloaded, sensitive, or excluded from version control should be placed at the
paths specified by each script. Generated figures, tables, and intermediate analysis files are
written to the repository output directories defined in the corresponding scripts.
